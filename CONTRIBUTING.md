# Contributing Guide

Thank you for your interest in contributing to this project.  
We welcome code improvements, bug fixes, documentation updates, and feature suggestions.

## Code of Conduct

- Be respectful and inclusive in all community interactions.
- Follow open-source best practices and keep contributions clean and reviewable.

## License and CLA

This project is licensed under the MIT License. All contributions will be licensed under the same license.

**Before contributing, please read the Contributor License Agreement: [CLA.md](./CLA.md).**

**By submitting a pull request, commit, patch, or any other contribution, you automatically accept the terms of the CLA.** No separate signature or offline confirmation is required.

If you do not agree with the CLA, do not submit a contribution.

## Pull Request Guidelines

1. Fork this repository and create your feature branch from the latest `main` branch.
2. Keep changes small and focused. Use clear, concise commit messages.
3. Build and test your changes before submitting.
4. Open a pull request with a clear title and description, including what the change does and why it is needed.

## Contribution Rules

- Keep contributions original and compatible with the MIT License.
- Do not submit third-party code, assets, or other material unless it is clearly identified, properly attributed, and released under a license compatible with MIT.
- Do not copy proprietary Minecraft server/client code, resources, or assets.
- Do not submit code under GPL, other strong copyleft licenses, or proprietary licenses unless you have confirmed compatibility with the maintainers.
- When in doubt about license compatibility, ask the maintainers before submitting.
- Maintainers may accept, reject, or request changes to any contribution.
